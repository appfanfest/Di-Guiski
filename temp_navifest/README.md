
# 🎄 NaviFest AR | Metaverso Navideño

![Version](https://img.shields.io/badge/version-5.0.0-red)
![Platform](https://img.shields.io/badge/platform-Atlantis_5.0-green)

NaviFest AR es una infraestructura inmersiva avanzada diseñada para la gestión y activación de experiencias de Realidad Aumentada (RA) durante la temporada navideña y año nuevo.

## 🚀 Características
- **Catálogo Inmersivo:** Gestión dinámica de filtros para TikTok, Snapchat e Instagram.
- **Editor Pro:** Herramienta web para el diseño de postales digitales personalizadas.
- **Atlantis 5.0 Core:** Infraestructura escalable con Supabase y React 19.
- **Asistente AI:** Integración con Google Gemini para atención al usuario.

## 🛠️ Tecnologías
- **Frontend:** React 19 + Tailwind CSS
- **Backend-as-a-Service:** Supabase (Auth, DB, Storage)
- **Inteligencia Artificial:** Google Generative AI (Gemini 3 Flash)
- **Deployment:** Vercel

## 📦 Instalación

1. Clona este repositorio.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Configura tus variables de entorno en un archivo `.env`:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `API_KEY` (Gemini API)

4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
